# Security policy

Report suspected approval bypass, secret exposure or policy bypass using
[GitHub private vulnerability reporting](https://github.com/akhilthomas011/citadel-agent/security/advisories/new).
Include the affected version, reproduction steps and change-set ID when
available. Never include keys, access tokens or unredacted conversation
transcripts in a public issue.

See the [security model](docs/security.md) for the trust boundaries, deployment
controls and known limitations. DevUI is a local development interface, not a
production multi-user application or authorization boundary.

The project is preparing v1.0. No long-term support or security response-time
guarantee is currently offered; use the latest reviewed revision.
